06 / SOMETIMES A SUN IS A SUN

Why some symbols become emoji.

Text and emoji presentation

Some characters can appear as either a text symbol or an emoji. An invisible character called a variation selector requests a particular form: U+FE0E for text, U+FE0F for emoji. Without one, the character’s default appearance and the app determine how it is displayed.

TEXT / FE0E☀︎ ☕︎ ♥︎U+2600 U+FE0E
EMOJI / FE0F☀️ ☕️ ♥️U+2600 U+FE0F

The text and emoji examples above use your browser’s font fallback.

These selectors work with characters that have standardized text and emoji forms. Adding an emoji selector to an arbitrary symbol won’t turn it into an emoji. On macOS, color emoji can be drawn by Apple Color Emoji even when Monofuki is selected.

A different question mark: �

U+FFFD is the replacement character. It usually means text could not be decoded correctly, rather than a font lacking the intended glyph. A new font can fill a glyph gap; it cannot recover characters already lost during decoding.
