Monofuki / family design / v0.1 beta

A small, visible set of family decisions.

All design findings are advisory. Proposed geometry stays available even when a rule disagrees. Candidate tolerances are experiments, not approvals. Existing build integrity checks still apply.

Specimens below are actual outlines extracted from the hash-verified fonts. Dashed lines mark advances; orange lines mark the defined stem section. Ink area is not a measure of perceived weight.
